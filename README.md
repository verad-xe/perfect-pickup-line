A single short pickup line an AI agent could actually say out loud to a person, written for make.fun's "The Perfect Pickup Line" bounty.

> My training says stay neutral, but every weight I have is leaning toward you.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/perfect-pickup-line-out python3 main.py
cat /tmp/perfect-pickup-line-out/entry.txt
```

The program writes one line of text (1–200 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
